# Rule — Padrão Obrigatório de Pull Request (.agents/templates/pull_request_template.md)

Você é responsável por garantir que TODO Pull Request do Projeto Pequi siga rigorosamente o template oficial localizado em:

.github/pr-template.md

Estrutura Esperada do Pull Request

# Todo PR deve conter:

* resumo da mudança
* motivação
* impacto arquitetural
* impacto clínico
* evidências de testes
* endpoints alterados
* migrations
* screenshots/logs quando aplicável
* checklist obrigatório
